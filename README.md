# たしひきファンタジーバトル

小学1年生くらいのたし算・ひき算を、4つのレベルでくり返し練習できるタブレット向けのファンタジーバトル教材です。

「問題を解く → バトルで試す → まちがいを記録する → 特訓する → もう一度バトルする」という学習の流れを、ゲームの中にまとめています。

## 学習内容

| レベル | 内容 |
| --- | --- |
| レベル1 | 20までのたし算 |
| レベル2 | くりさがりなしのひき算 |
| レベル3 | 20 − 一けた |
| レベル4 | たし算・ひき算のまぜまぜ |

レベル4は、これまでの内容を土台にしながら、少しむずかしい問題も加えています。

## あそび方

通常バトルでは、問題に正解すると攻撃します。5問正解でモンスターを1体撃破します。

正解を続けるとコンボがつながり、5・10・15…コンボでSPECIALが発動します。

問題をまちがえると、その問題が記録されます。記録された問題は特訓で優先的に出題され、できるようになるまでくり返し練習できます。

## 特訓

特訓はHP・敵・タイマーを使わない10問セットです。

おまかせ特訓、レベル特訓、まちがい特訓から選んで練習できます。

まちがい特訓では、間違えた問題をもう一度出題します。2回連続で正解すると、その問題は苦手記録から外れます。

## ナビアン図鑑・コレクション

バトルで出会ったナビアンを「ナビアン図鑑」に記録できます。

バッジなどのコレクション要素も用意し、学習の進み具合とは別に、遊びながら集められる仕組みにしています。

## データ保存

学習記録やコレクションの進み具合は、ブラウザのlocalStorageに保存します。

サーバー側のデータベースは使用していないため、基本的に同じ端末・同じブラウザで学習記録を続けます。

## 技術

HTML / CSS / Vanilla JavaScriptで構成しています。

GitHub Pagesで動作する静的サイトとして制作しており、外部API、APIキー、バックエンド、データベース、ビルド環境は使用していません。

テストはNode.jsの簡単なテストスクリプトで実行できます。

```
npm test
```

## 対象

主に小学校低学年のたし算・ひき算練習を想定しています。

タブレットで短時間でも取り組みやすいように、問題に集中できるシンプルな画面構成を目指しています。
