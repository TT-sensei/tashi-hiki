# たしひきファンタジーバトル

小学1年生くらいのたし算・ひき算を、4つのレベルで練習するファンタジーバトル教材です。

## 4つのレベル

レベル1：20までのたし算。
レベル2：くりさがりなしのひき算。
レベル3：20−一けた。
レベル4：たし算・ひき算のまぜまぜ。

レベル4は、これまでの内容を中心に、少しむずかしい問題もまぜます。

## 学習の流れ

バトル → まちがい記録 → 特訓 → もう一度バトル。

通常バトルは5問正解でモンスターを撃破します。
正解を重ねるとATTACK、5・10・15…コンボでSPECIAL。
間違えた問題は自動で特訓につながります。

## 特訓

HP・敵・タイマーなしの10問セットです。
おまかせ特訓、レベル特訓、まちがい特訓を用意しています。
間違えた問題はあとでもう一度出題され、2回連続で正解すると苦手から外れます。

## 図鑑・コレクション

モンスター図鑑とコレクションを用意しています。
学習の進み具合とは別に、モンスターやバッジを集めていけます。

## 技術

HTML / CSS / Vanilla JavaScript、GitHub Pages、localStorage。
外部API・APIキー・DB・BGMは使用しません。
